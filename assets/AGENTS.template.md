# 项目原型协作入口

> 使用说明：将下文中的文档链接替换为真实路径，移除不存在或不适用的引用，完成后删除本提示。与现有 AGENTS.md 合并，不覆盖现有约束。此模板提取自真实项目的协作结构，不继承其业务名称或目录隔离规则。

本文件规定当前原型目录的任务边界、权威文档、协作与验证要求。目录归属和样式维护方法见[项目组织与维护指南](docs/project-guide.md)，不在此重复目录清单或 CSS 细则。

## 任务边界与权威依据

1. 本目录聚焦前端展示、页面方案和本地模拟的演示交互，不默认建设完整前后端业务；仅在本轮授权范围内修改。外部项目仅作为参考，不默认同步修改。
2. 产品范围与流程以项目指定的 PRD 为准；在此填写实际 PRD 路径。PRD 可放 docs/prd/ 或沿用现有目录，只作为输入。PRD 编写、代码与 PRD 对齐及覆盖矩阵由独立 Skill 维护，本原型流程不承担。
3. 视觉、token、控件状态与响应式以[设计规范](DESIGN.md)为准。每次新增页面先读取相关规范和公共组件，历史页面的特殊样式不能成为新依据。
4. 新增、移动或清理组件与样式遵循项目维护指南；反复出现的元素优先复用或提取共享组件。
5. 用户当前明确要求优先于历史决定；权威文档冲突时说明差异与影响，无法判断的重要分歧由用户裁决。

## 更新模式的边界

- 修改导航、布局和新增页面均属于更新；默认沿用技术栈及 DESIGN.md，按本轮明确要求调整，不擅自改变无关结构。可先提出有依据的重构建议，非必需重构不阻塞当前任务，额外重构经用户确认后执行。
- 修改共享组件、全局样式或公共 Mock 前先查调用方。局部需求使用明确变体，保留其他调用方的默认行为和数据关联。
- 本轮未提到的入口、交互和状态继续保留；发现无关问题只报告，不顺手修复。必要关联调整说明原因；超出局部更新边界时先确认范围。
- 依据实际影响做代码级回归检查，区分原有失败与本次新增失败；不声称未经检查的功能绝无回归。

## 参考与实现

- 参考页面仅在指定范围内用于功能、交互或视觉，不直接搬入无关模块。已采用视觉必须落实到 DESIGN.md。
- 所有按钮、选择器、输入与浮层及其交互状态遵循设计规范；不使用依赖系统默认外观的控件表现。下拉选项由项目组件绘制，不使用原生 select 弹层。
- 保留语义和无障碍能力：键盘操作、可见焦点、适当的焦点管理及触控行为。
- 本轮演示任务具有明确入口、操作和可见结果，范围内按钮有有效响应。路由页面支持直接打开、刷新、前进后退。
- Mock 覆盖本轮各业务状态和展示边界，并有可到达、可重置的演示路径；列表、详情与统计保持一致，加载和错误场景可确定性复现。真实事实、估算、演示和未知字段明确区分。
- 保持类型和数据边界明确，错误、空数据与加载状态按流程提供恢复方式。
- 保留用户已有未提交改动，不随意增加依赖，不提交密钥或真实用户敏感数据。

## 启动与分享

- 首次项目可运行后自动启动，提供实际打开地址和以后启动/停止的方法；修改可热更新时不重启，确需重启则自动完成并复查服务响应。
- 核对进程归属，只管理当前项目服务，不结束占用端口的无关进程。启动方式与端口记录在项目维护指南。
- 默认同时提供本机地址与可用的局域网 IP 地址；用户要求仅本机时遵守。局域网分享需非回环监听和实际网卡 IP，不以 localhost 或 0.0.0.0 作为分享地址。
- 用日志、监听状态和 HTTP 请求检查，不打开浏览器或截图；本机响应不代表其他设备连通已验证。局域网地址需同网可互通且电脑与服务持续运行，不自动建立公网隧道或同步后端。

## 验证与交付

- 仅做最小充分代码验证：类型检查、相关非浏览器测试及必要 lint；路由、配置或跨模块修改再增加构建。禁止删除测试、放宽类型或屏蔽错误来通过验证。
- 制作或修改原型时，不做浏览器检查、截图或浏览器自动化测试。
- 每次修改列出具体页面/区域、修改前后、实际文件位置和验证结果，在交付回复提供具体变化，不能只列文件名或笼统说优化。不新增或维护独立状态记录、改动日志；正式原型以 Git 管理版本，已有记录不擅自删除。说明已知限制，不声称代码检查证明视觉正确。
- 未经用户明确要求，不提交、推送、创建分支或修改远端状态。
- 设计与组织规则变化同步对应原型文档；具体改动清单可交给独立 Skill 做 PRD 对齐，本流程不执行需求同步。避免把前端演示成功等同于真实后端能力已实现。
